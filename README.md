# AI Service Integration Prototype

A production-ready REST API built with **FastAPI** that uses a trained **scikit-learn GradientBoostingRegressor** to estimate property market values. The API validates all inputs via **Pydantic**, is containerised with **Docker**, and is covered by **pytest** unit tests.

---

## File Structure

```
ai-service-prototype/
├── main.py            # FastAPI app + Pydantic schemas + ML predictor wrapper
├── train_model.py     # Trains and saves the sklearn model to model.joblib
├── model.joblib       # Serialised trained pipeline (generated by train_model.py)
├── test_main.py       # pytest test suite
├── requirements.txt   # Python dependencies
├── Dockerfile         # Multi-stage Docker build
├── .dockerignore
├── .gitignore
└── README.md
```

## Quickstart (Local)

### 1. Create a virtual environment and install dependencies
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Train the model (generates model.joblib)
```bash
python train_model.py
```

### 3. Start the API
```bash
python main.py
# or
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

### 4. Open interactive API docs
- Swagger UI → http://127.0.0.1:8000/docs
- ReDoc      → http://127.0.0.1:8000/redoc

## API Reference

### `POST /api/v1/predict`

**Request body (JSON):**

```json
{
  "square_footage": 1500.0,
  "num_bedrooms": 3,
  "num_bathrooms": 2.0,
  "age_years": 10,
  "location_tier": "suburban",
  "has_garage": true
}
```

| Field           | Type    | Constraints                             |
|-----------------|---------|-----------------------------------------|
| square_footage  | float   | 200 < value ≤ 20,000                    |
| num_bedrooms    | int     | 1 – 20                                  |
| num_bathrooms   | float   | 1.0 – 10.0, multiples of 0.5            |
| age_years       | int     | 0 – 200                                 |
| location_tier   | string  | `"urban"` \| `"suburban"` \| `"rural"`  |
| has_garage      | bool    | `true` / `false`                        |

**Success response `200 OK`:**

```json
{
  "status": "success",
  "predicted_value_usd": 231450.75,
  "confidence_score": 73.26,
  "input_summary": { "...": "..." },
  "model_version": "2.0.0-gbr"
}
```

**Validation error `422`:**

```json
{
  "status": "error",
  "detail": "[body -> location_tier] Input should be 'urban', 'suburban' or 'rural'"
}
```
